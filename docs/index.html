CSS-first UI kit · sheet 1

Interfaces drawn like technical drawings.

Blueprint Paper is a small stylesheet. Navy paper, pale ink, one monospace face, and controls whose state you can read from the line work: hollow is off, filled is on. No JavaScript required for any component.

Install See the demo

Install

One stylesheet. Load it, then put bp-sheet on <body>. The kit uses IBM Plex Mono and falls back to the system monospace if you don't load it.

From the CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/streamlinedesign/blueprint-paper@main/dist/blueprint-paper.min.css">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@300;400;500&display=swap">

From npm

npm install blueprint-paper
import 'blueprint-paper';            // everything
import 'blueprint-paper/tokens';     // or tokens + just what you need
import 'blueprint-paper/components/switch.css';

Everything lives in cascade layers (bp.tokens, bp.base, bp.components), so any CSS you write outside a layer overrides the kit without !important.

Typography

One face, IBM Plex Mono, in three weights. Large display sizes are light (300), body is regular, labels are medium and uppercase with wide tracking, like annotations on a drawing.

Inline code and Ctrl K get a hairline box. Links are underlined ink.

Bare h1–h4 inside .bp-sheet get the L, M, S and label sizes. The .bp-display--* classes set a size on anything.

Switch

The component the kit started from. A pill switch hides its state in a color and a knob position. Here the state is in the line work: a hollow thumb on the left (or bottom) is off, a filled thumb on the right (or top) is on. The track is always solid.

  <span class="bp-switch__track"></span>
</label>

</label>

Motion

  • 180ms slide on a custom ease-out. Under 300ms, never the built-in curves.
  • The thumb's leading edge sets off first and the trailing edge follows 35ms later, so it stretches through the slide and settles on the far side, like a lever under load. Nothing happens on press.
  • Keyboard (Tab, Space): flips instantly. Keyboard actions are never animated.
  • prefers-reduced-motion: every transition is removed.
  • The hit area is at least 44 × 44px on every size.

Toast

Inspired by the shadcn/ui toast (Sonner, by Emil Kowalski). Toasts stack the same way: the newest in front, older ones peeking out behind. Hover or focus the stack and it fans out and the timers pause. Swipe one sideways (or drag it with a mouse) to clear it. The region is a live region, so screen readers announce each one. Showing them needs the optional script; the styles alone give you a static toast.

SavedRev B2 issued on sheets 3 and 7.
Pump B stopped
bp.toast('Saved', 'Rev B2 issued on sheets 3 and 7.');
bp.toast('Pump B stopped', 'Stopped by operator.', { solid: true, duration: 6000 });
bp.toast.dismiss();                 clears all; pass a toast element to clear one

<div class="bp-toasts bp-toasts--top" role="status" aria-live="polite"></div>   optional: place the region yourself

Region position: --top, --left, --center on .bp-toasts.

Measure

A dimension line with end ticks and a label, the way sizes are marked on a drawing. Pixels by default; mm, cm and inches are converted at CSS resolution (96 px per inch), so a screen millimetre, not a ruler one. A scale such as 1:50 multiplies the shown value.

Standalone lines

data-measure needs the optional script below. --ink draws the line in full ink; the default is 72% so measurements sit behind the content.

Code

A plain <pre><code> is already drawn as a block. Add data-code and the optional script gives it line numbers and a Copy button, like every block on this page. data-code="copy" for the button only, data-code="numbers" for numbers only. One-line blocks get no numbers unless you ask.

.bp-switch {
  --w: 52px;
  --h: 28px;
}
<pre data-code><code>…</code></pre>
<pre data-code="copy"><code>npm install blueprint-paper</code></pre>

From script: bp.code(pre, { numbers: true, copy: true }). Without the script, the same look is a .bp-code wrapper, one .bp-code__line span per line and a .bp-code__copy button, so a static site generator can produce it at build time.

Progress

A bar with a solid fill, or section hatching the way a cut surface is marked on a drawing. The indeterminate one slides its hatch. Set the value as a custom property and in aria-valuenow.

<div class="bp-progress" role="progressbar" aria-valuenow="40" aria-valuemin="0" aria-valuemax="100" style="--value: 40%">
  <span class="bp-progress__bar"></span>
</div>
<div class="bp-progress bp-progress--hatched" …>            hatch fill
<div class="bp-progress bp-progress--indeterminate" …>      no value: the hatch slides
<span class="bp-progress__bar" data-label="25%">            value drawn at the bar's end (--lg fits it best)

Sizes: --sm (6px), default (12px), --lg (20px). The fill animates between values at 180ms.

Skeleton

A loading placeholder drawn as a draft: dashed outline, faint hatch, a slow pulse. One of the few places the kit uses a dashed line, because here it means "not yet drawn".

  <span class="bp-skeleton bp-skeleton--line"></span>
  <div class="bp-skeleton" style="height: 96px"></div>

Optional script

The CSS needs no JavaScript. blueprint-paper.js (3 kB, no dependencies) adds the few things only script can do. Load it and you get:

  • data-measure dimension lines that follow the element's size.
  • Menus close when you click elsewhere.
  • bp.toast('Saved', 'Rev B2 issued.', { solid: true, duration: 4000 })
  • bp.theme('whiteprint') sets and remembers the theme; bp.theme() reads it.
  • bp.format(240, 'mm') → 63.5 mm, and bp.measure(el) to measure an element you add later.
  • <pre data-code> blocks get line numbers and a Copy button; bp.code(pre) for one you add later.
  • Code blocks and table wrappers get tabindex="0" so keyboards can scroll them.
<script src="https://cdn.jsdelivr.net/gh/streamlinedesign/blueprint-paper@main/dist/blueprint-paper.js" defer></script>
import 'blueprint-paper/js';
